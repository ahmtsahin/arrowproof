    An arrow A → B is verified when a file in A imports a file or a package in B. Arrows marked as flow pass with an import in either direction. Calls through HTTP, queues, dependency injection or computed imports are not visible to this check, so an unverified arrow is a claim without evidence, not proof of a bug.
